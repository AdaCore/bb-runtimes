# Porting a runtime to a Cortex-M board

The updated tutorial is part of the [bb-runtimes manual](https://bb-runtimes.readthedocs.io/en/latest/user_guides/porting_cortex_m.html), under “Extending with Your Own Target”.
The exercise builds an STM32 board target in the [extender template](https://github.com/AdaCore/bb-runtimes-extender-template), using the supported boards as references.

The numbered Markdown chapters in this directory describe the former infrastructure.
Use the manual for current commands and source locations.
